# LoL Coach — 初心者向け上達デスクトップアプリ 設計書

日付: 2026-11-19
状態: 承認済み（brainstorming にてユーザー承認）

## 目的

『LOLの教科書』（チャレンジャー著、著者の許可あり・全文同梱可）を元に、
LoL 初心者が「知識 → 判断 → 実戦の習慣」を一つのアプリで回せるようにする。

教科書の核となる考え方:

- ソロランクは 7 科目の試験（TOP / JG / MID / ADC / SUP / マクロ / 集団戦）。0 点科目がティアを止める。
- ガンク優先度の大前提は「ボット > ミッド > トップ」。ただしチャンピオンのタイプ別マッチアップで「重要 O / X」が変わる。
- 練習ルール「3 戦セット」: 2 連敗で即終了、3 戦で 2 勝以上なら負けるまで続行。試合間に筋トレ。

## 形態・技術

- PC 用デスクトップアプリ（Windows 向け zip を配布物とする。macOS/Linux でも開発実行可）
- Electron + React + TypeScript + Vite、テストは Vitest
- 配置: ポートフォリオリポジトリの `lol-coach/` サブディレクトリ
- データ保存: Electron の `userData` 配下の JSON ファイル（サーバー不要）。ブラウザ実行時（開発用）は localStorage にフォールバック。

## 画面

1. **ホーム（ダッシュボード）**
   - 7 科目の理解度（各科目のドリル正答率、0〜100 点）を一覧表示し、最も低い科目を「次に学ぶ科目」として推奨。
   - 今日の練習セッション状態、通算勝率。
2. **教科書リーダー**
   - 章目次（見出し階層）、本文表示、全文検索、しおり、既読管理。
   - 元 .docx の図版はテキスト化で欠落するため v1 は本文のみ。
3. **判断力ドリル**
   - 選択式クイズ: 教科書の分類・ルールから作問。各問に科目タグ・解説・参照章。誤答は復習キューへ入り、優先して再出題。
   - ワークブック: 教科書内のワークブック／ドリルの設問を抽出し、記述回答を保存できる。参照章へジャンプ可能。自己評価（できた／あいまい／できない）。模範解答は v1 では教科書内に答えがある範囲で参照章リンクとして提供。
4. **マッチアップ判定**
   - トップ（タンク／ブルーザー／遠距離ディーラー）、ミッド（ロームT1〜T3／近接1v1／遠距離ファーム／レーン戦強い）、ボット（ADC 3 種 × サポート 5 種）について味方・敵のタイプを選択。
   - 教科書ルールで各レーンの「重要度」と根拠文を出し、ボット > ミッド > トップのタイブレークで最優先ガンク先を提示。Lv6 前後の切替あり。
5. **ランク練習セッション（3 戦セット）**
   - 勝敗を入力すると、ルールに従い「続行／終了」を判定して表示。
   - 試合間の筋トレタイマー（限界まで 1〜2 セット）。
   - 試合ごとの振り返りメモ（「今日の悟り」9 行ノート）。
   - 勝率推移の簡易グラフ。

## コアロジック（純粋関数・TDD 対象）

- `session.ts`: 3 戦セット判定 `evaluateSession(results: ('W'|'L')[]) -> { status: 'continue'|'stop', reason }`
  - 2 連敗した時点で stop
  - 3 戦未満で 2 連敗していなければ continue
  - 3 戦終了時点で 2 勝以上なら continue（以後、負けた時点で stop）、1 勝以下なら stop
- `matchup.ts`: レーン別重要度スコアと最優先レーンの算出
- `scores.ts`: 科目別正答率と推奨科目
- `review.ts`: 誤答復習キュー（誤答を優先、正解で外す）
- `search.ts`: 教科書全文検索（章・行のヒット）

## 教科書データ

- Google ドキュメント版から取得したテキストを `scripts/build-textbook.mjs` で整形（Markdown エスケープ・装飾記号の除去）し、見出しで章分割した `src/content/textbook.json` を生成・同梱。
- ワークブック設問は同スクリプトで抽出し `src/content/workbook.json` に出力。
- 選択式クイズは `src/content/quiz.ts` に手書き（各問に参照章 ID）。

## スコープ外（v1）

- 図版の表示、Riot API 連携、自動試合記録、オーバーレイ表示、自動アップデート、コード署名。

## テスト・検証

- コアロジックは Vitest で先にテストを書く。
- 画面はビルド後に Playwright でレンダラーを起動しスクリーンショット確認。
- `electron-builder --win zip` で Windows 用 zip を生成できることを確認。

## 追加機能 v0.2（便利機能）

ユーザー選択: 記録のバックアップ / 試合中のミニ常駐ウィンドウ / 今日の課題 / チャンピオン名で検索

1. **記録のバックアップ**
   - 設定画面から全記録を JSON に書き出し・読み込み。Electron ではネイティブの保存/開くダイアログ、ブラウザ実行時はダウンロード/ファイル選択。
   - 読み込み時は `parseBackup()` で形式を検証し、不正なら何も変更せずエラー表示。読み込み前に確認ダイアログ。
2. **ミニ常駐ウィンドウ**
   - 常に最前面の小ウィンドウ（約 380×620）。`Ctrl+Shift+L`（グローバルショートカット）またはサイドバーのボタンで開閉。
   - 内容: 今日の3戦セット（勝敗入力・判定）と、チャンピオン名で入力できる簡易ガンク判定。
   - 2つのウィンドウ間の記録は、メインプロセスが保存のたびに他ウィンドウへ通知して同期する。
3. **今日の課題**
   - `buildDailyPlan(date, …)`: 推奨科目から3問（誤答 → 未回答 → 正解済みの順）＋関連する未読の教科書1章。日付ごとに固定。
   - ホームに達成状況つきで表示し、ワンクリックでその3問だけのドリルへ。
4. **チャンピオン名で検索**
   - 教科書に登場する分類（トップ/ミッド/ADC/サポートのタイプ、ジャングル）とガイド章を持つチャンピオン辞書。
   - かな/カナ・記号・空白の違いを無視して検索（`searchChampions()`）。
   - チャンピオン画面: 分類・関連ガイド章へのリンク・「ガンク判定に入れる」。ガンク判定の各枠にも名前入力欄を付け、タイプを自動選択。

## 追加機能 v0.3（推奨機能の残り全部）

1. **試合後の振り返りチェックリスト**
   - 教科書の判断基準7項目（ガンク先を重要度で決めた／初手ルートを構図で選んだ／視界→オブジェクトの順／視界を失ったらクロス／劣勢時に無理をしない／フルクリア後の判断を視界で決めた／最後まで冷静）を、3戦セットの各試合でチェック。
   - `checklistStats()`: 項目ごとの達成率と、勝ち試合・負け試合での達成率の差から「勝敗を分けている習慣」を表示。
2. **ジャングルルート練習**
   - 教科書の序盤ルート一覧（狩る順のキャンプを図示、使う条件）と、構図からルートを選ぶ4択シナリオ。回答は JG 科目の点数に含める。
3. **プロのリプレイ分析ノート**
   - 1件 = 選手・チャンピオン・ロール・時刻・状況・動き・理由・気づき。著者の「毎日9本観戦」に合わせて今日の本数を表示。気づきは「悟り」ノートへ送れる。
4. **教科書の図版**
   - Google Drive 連携のサイズ上限（10MB）で元 .docx（74MB）を取得できないため、アプリ内で利用者が手元の .docx を選んで取り込む。
   - `word/document.xml` の段落を順に読み、見出し文字列で章を特定して直後の画像をその章に割り当てる（`mapDocxImages()`）。画像は userData に展開し、専用プロトコルで表示。
