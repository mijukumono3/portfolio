# LoL Coach

『LOLの教科書』（著者の許可を得て同梱）で学ぶ、League of Legends 初心者向けの上達デスクトップアプリです。

## 機能

- **ホーム**: 7科目（TOP / JG / MID / ADC / SUP / マクロ / 集団戦）の点数と「次に学ぶ科目」
- **3戦セット**: 教科書のルール（2連敗で終了、3戦2勝以上なら負けるまで続行）を自動判定。筋トレタイマー、試合ごとの振り返り、「悟り」ノート、勝率推移
- **判断力ドリル**: 教科書に基づく4択クイズ78問。誤答は優先して再出題
- **ワークブック**: 教科書の記述式設問37問に回答し、模範解答と比べて自己採点
- **ガンク判定**: 味方・敵のタイプからガンクの優先順位と根拠を表示
- **教科書**: 全251章の目次・全文検索・しおり・既読管理

記録は PC 内（`%APPDATA%/lol-coach/lol-coach.json`）に保存されます。

## 開発

```bash
npm install
npm test          # ロジックとデータのテスト
npm start         # ビルドして Electron で起動
npm run dist:win  # Windows 用 zip を release/ に作成
```

教科書テキストを更新した場合は `content-src/lol-textbook.txt` を差し替えて `npm run textbook` を実行します。
